# 42BV Homebrew Tap

Homebrew casks maintained by 42BV.

## Install Normatik CLI

```bash
brew install --cask 42bv/tap/normatik
```

The `normatik` cask is published here by the Normatik CLI release process.
It installs the checksummed macOS binary for the current release.

The first CLI release adds `Casks/normatik.rb` and publishes its immutable
macOS archives to this repository's GitHub Releases.

## Support

Report issues with the Normatik CLI through the normal Normatik support channel.
This repository contains Homebrew packaging metadata only.
